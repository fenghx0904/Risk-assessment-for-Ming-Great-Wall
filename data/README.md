# Data directory

`processed/analysis_input.xlsx` is the compact input used by the public analysis. It contains the 11 factor values already assigned to each assessment unit, plus the heritage attributes required to calculate vulnerability and protection capacity.

The factor rasters are excluded because they are large and include third-party source products with separate redistribution terms. See `metadata/DATA_PROVENANCE.md` and `../docs/BAIDU_NETDISK_UPLOAD_CHECKLIST.md`.
